There are three ways to use CSS in our page

  • Inline
    • " (angle bracket)tag style="css"(/greater-than sign)
    • This goes in the html tag: html style='background: blue'
      this is just for a single element on the page, but will be not recommend for a lot of attributes
  • Internal
    • " (angle bracket)style(greater-than sign) css (/angle bracket)style(greater-than sign)
    • lest suppouse he have
      html
      head
      style
      html{background:red ....}
      and close every of the tags
      this is the internal it is a tag only for css but not on a different file, in this case we can add more attributes in the tag style but if we have a multipage this will not work
  • External
    • " (angle bracket)link href="style.css"/(greater-than sign)
    • This is the part where the css goes to a different file, and to called it we do
      html
      head
      link rel='stylesheet' href='./styles.css'
      and the rest
      as we can see this is the most useful way to use a css file without mixing the same file

CSS Selectors

h1{
color: green;
}
The h1 IS OUR CSS SELECTOR This is the part of HTML to apply the rules inside the brackets, also call in this case
ELEMENT SELECTOR

Class Selector

(CSS FILE) This take a special symbol, that is a dot, and then the namme of the class

Leets supposed he have a h1 of color blue but another h1 need to be red, well with classes instead of element selector, we can do this
h1 class="blue-class"... h1 class="red-class" the class can have any name that we wanted but need to be the same on the css file

ID Selector

(CSS FILE) This take a special symbol, that is a hashtag (#), and then the namme of the id

h2 id="name_id"... and for the rest of it

What is the difference between id and class selector

The class can be apply to many elements
Meanwhile the id should be only apply to a single element

Attribute selector

p[draggable]{color:red}

  • p is for html element
  • [draggable] is the attribute
  • {} select all paragraphs elements with the attribute draggable and apply whats is inside the brackets

We can also put conditions like p[draggable="false"]{color:blue} to make it more specific

Universal Selector

*{color: purple}

This will change for all the tags, p, h1,2,3.., even if they have classes, ids, or attributes
